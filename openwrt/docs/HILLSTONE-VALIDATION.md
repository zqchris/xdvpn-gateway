# Hillstone 实现与验证摘要

SCVPN 原生 Go 核心已在一套 x86_64 OpenWrt 派生固件上验证。
详细现场记录私下保留；公开文档不含业务地址、拓扑、服务器指纹或原始协议载荷。

## 协议与生命周期

- TLS 证书验证后认证，协商网络参数和 UDP/ESP 密钥。
- 验证 TUN 收发、业务 HTTPS、LAN 转发、主动断开及清理。
- 明确的服务器终止报文结束会话；控制通道正常 EOF 不单独作为 UDP 会话失效依据。
- 有界健康探测与退避重连；拒绝认证、证书不匹配等错误不无限重试。

## 分流

手动模式只接管用户填写的域名和 IP。公司模式合并管理员提供的私人预设与手动项。
服务器下发的全网路由不作为公司业务分类依据。全局模式需用户主动选择。
自定义黑名单在全部模式优先排除；内置 Anthropic 保护在手动/公司模式默认启用，全局模式忽略该内置保护。

公司域名使用 dnsmasq nftset 学习 IPv4；父域名包含自身及子域名。
保存规则通知现有进程刷新，防火墙事件恢复自有规则，定期审计仅在缺失时修复。
这些规则在已测的 fw4/OpenClash redir-host 环境生效，不构成所有代理模式的兼容承诺。

## 性能与可观察性

核心没有 Python、抓包进程或额外通用代理引擎。轻负载快照 RSS 约 8–9 MiB，不能作为所有负载或架构的内存上限。
缓冲区、访问记录和连接元数据有界；访问记录仅存内存，重连清空。
仅在确实送入 Hillstone 传输后记录访问，不将规则推断冒充实际访问，也不将发送成功等同于业务成功。

完整限制见核心 README 与验收摘要。
